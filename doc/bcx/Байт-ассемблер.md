# Байт-ассемблер

- минимально-возможный язык, предназначенный только для раскрутки минимальной диалоговой системы из её текстового определения

## нестандартный [[Форт]]

- генерация высокоуровневой части командной консоли
- `src/bcx.lex` лексер на [[syntax/flex|flex]]
- `src/bcx.yacc` парсер на [[syntax/bison|bison]]

## комментарии

- первая строка может начинаться с `#!` shebang: запуск файла как скрипта
- `\` строчный комментарий (не путать с делением `/`)

## типы данных

### атомарные типы

- `byte`: байты ([[u8]])
- `cell`: целые числа ([[i32]] signed int)
	- `addr`: адреса виртуальной памяти ([[u16]])
	- `phys`: физические адреса MCU ([[u32]])
- `bool` нет, используется сравнение с нулём
	- `false = 0`
	- `true != 0`

```cpp
typedef  uint8_t byte;  ///< single byte (u16)
typedef  int32_t cell;  ///< signed integer (MCU-limited: 32bit)
typedef uint16_t addr;  ///< virtual memory address (16 bit, 64K max)
typedef uint32_t phys;  ///< physical memory address (MCU)
```

### строки

- 8-битные строки с байтовым счётчиком и конечным нулём
	- быстрое сравнение на неравенство: сравнение 2х байт
	- совместимость с сишными строками: кончаются нулевым байтом
	- хранение коротких меток и сообщений и команд на 1-2 строки
	- работа с текстом не предполагается
