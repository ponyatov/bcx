# С-подобный язык с компиляцией в байт-код

Для мира и сообщества встраиваемых систем -- наиболее привычный язык Си. Фронтенд для статического подмножества C (без динамического выделения памяти, без рекурсии, с явным управлением памятью) может быть значительно проще. Здесь нет сложной динамической семантики. Переменные могут быть отображены непосредственно на ячейки памяти в адресном пространстве процесса, а функции — на адреса в коде.

Основная задача фронтенда для C — преобразовать императивные конструкции с инфиксной нотацией (например, `a = b + c * d;`) в последовательность стековых операций. Ему также потребуется реализовать доступ к элементам массивов и структур через вычисление смещений.

Для низкоуровневого программирования драйверов и критичных к производительности алгоритмов естественно рекомендуется использовать промышленный компилятор Си, на котором собственно написан и движок байт-кода. Создание Си-фронтента будет в нашем случае скорее учебной задачей, или в случае заказчика который упирается копытами и не хочет видеть в проекте никаких няшных языков, кроме расово-верной Сишечки.
