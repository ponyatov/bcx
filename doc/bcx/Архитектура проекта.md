# Архитектура проекта

- `main`
	- компилятор `.ini`/`.f` (нестандартный Форт)
		- `bcx.lex` `bcx.yacc`
- `vm`
	- ядро интерпретатора байт-кода
	- системо-независимые команды и примитивы

## Структура каталогов

- `bcx` система мультиплатформенная, поэтому файловая структура проекта довольно развесистая

```
.vscode/
ref/
tmp/
```
- исходный код ядра
	- только интерпретатор байткода, без верхнего уровня
```
inc/
	*.hpp
src/
	*.cpp
cmake/                        \ CMake
	x86_64-linux-gnu.cmake    | target: Linux x86/64
	any_toolchain.cmake       | общая часть для всех тулчейнов
	src.cmake                 | поиск файлов с исходым кодом ядра
	syntax.cmake              | синтаксис: лексеры/парсеры
CMake*                        /
```
- документация
```
doc/
	html/                | doxygen reference на ядро (сишная часть)
	bcx/                 | копия черновиков книги в Obsidian.md
```
- скрипты сборки и управления проектом
```
mk/                           \ GNU make (Linux, mingw/msys,.. POSIX)
	*.mk                      /
```
- бинарные сборки ядра интерпретатора для разных целевых платформ:
```
bin/
	bcx_pc_linux         | бинарник для Linux  (x86/64 ELF)
	bcx_i386_linux.iso   | миниLinux для ретрокомпьютеров (486dx+)
	bcx_rpi3_linux       | сборка для Rpi3B+   (32 bit)
	bcx_aarch64_linux    | сборка для Rpi3/4/5 (64 bit)
	bcx_pc_mingw32.exe   | Windows x32 (WinXP+) для совместимости
	bcx_f429disco.elf    \ сборки прошивок для отладок STM Discovery
	bcx_f4disco.elf
	bcx_iskra.elf
	bcx_pillf103.elf
	bcx_pillf030.elf     /
lib/                     \ высокоуровневый код
	bcx.ini              | штатный файл инициализации
	*.f                  / модули (библиотеки)
apt.Debian               \ Debian GNU/Linux 12+
apt.Raspbian             | списки зависимостей пакетов
apt.Ubuntu               / Ubuntu LTS
```
