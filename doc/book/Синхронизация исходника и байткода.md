# Синхронизация исходника и байткода

Компилятор сохраняет **карту фрагментов** для каждого слова — диапазон адресов его байткода и диапазон строк исходника. Расширение использует её для двусторонней навигации:
- из дизассемблера — прыжок к исходнику слова, и подсветка региона в дампе памяти;
- из исходника — подсветка соответствующего фрагмента байткода;
- при пошаговом исполнении курсоры и подсветка кода/дампа автоматически следуют за `Ip`

Карта фрагментов также позволяет **сворачивать** в редакторе тела слов в одну строку с показом стекового эффекта — полезно для больших файлов, где слов много, а тела короткие.
