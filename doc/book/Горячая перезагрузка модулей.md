# Горячая перезагрузка модулей

Изменение кода модуля (процесса) в редакторе перекомпилирует только этот модуль, и рестартует соответствующие процессы без перезапуска ВМ.

Редактирование кода на уровне отдельных слов не поддерживается из-за особенностей реализации компилятора:
- перекомпиляция слова изменит его размер
- потребуется перемещение кода, скомпилированного после
- для всего изменённого/перемещённого кода потребуется рекурсивная перезапись адресов во всех местах где этот код (или данные) используется

С другой стороны передача сообщений обеспечивает сверхпозднее связывание:
- что позволяет обрабатывать сообщения старой версией кода, пока не будет готова новая версия, 
- рестартовать процессы порожденные на основе измененного модуля, не отключая старые
- и переключить обработку сообщений только после того как все новые процессы будут готовы и инициализированы.

Это сокращает цикл «правка → проверка» до секунд и делает интерактивную разработку возможной даже на несильно нагруженном проде с реальными пользователями (естественно если ошибки в коде и сбои не приведут к значительным последствиям).
