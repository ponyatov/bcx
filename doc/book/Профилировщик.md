# Профилировщик

Поскольку ВМ отслеживает каждый шаг цикла выборки-исполнения, расширение может собирать **профиль исполнения** через DAP без отдельного инструмента:

- счётчик срабатываний по каждому адресу байткода (гистограмма «горячих» слов);
- время, проведённое в каждом слове (по меткам на входе/выходе);
- глубина стека данных во времени — график, по которому видно пики и потенциальные переполнения;
- количество вызовов и средняя глубина рекурсии по стеку возвратов.

Результаты отображаются в отдельной панели и экспортируются в JSON для внешнего анализа. Для embedded это особенно ценно: профиль показывает, какие фрагменты кода стоит оптимизировать вручную, вынести в низкоуровневый код на С/С++, а какие и так укладываются в бюджет.
