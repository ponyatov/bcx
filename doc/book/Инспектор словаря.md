# Инспектор словаря

Расширение предоставляет runtime-доступ к таблицам символов ВМ/компилятора, и динамически отображает панель для просмотра и редактирования:
- дерево пространств имён и областей видимости;
- поиск слова по имени с переходом к определению и подсветке в дампе памяти;
- для каждого слова — адрес в `M`, размер кода, стековый эффект, число вызовов (из профиля);
- фильтры типа «только слова, определённые в текущем файле» и т.д.;
- пометка слов, которые ни разу не вызывались (кандидаты на удаление).
- декомпилятор и отладочный функционал (точки останова, задание уровня логирования для отдельных слов,..)
