# интеграция с IDE

Виртуальная машина и компилятор — это только половина системы программирования. Вторая половина — инструменты, которые делают разработку быстрой и приятной. Для [[bcx]] такой инструментальной средой выбран VSCode: он бесплатный, кроссплатформенный, расширяется через открытый API, и уже знаком большинству разработчиков.

Интеграция решает следующие задачи:

1. **Редактирование** — подсветка синтаксиса, автодополнение, навигация по определениям слов.
2. **Отладка** — пошаговое исполнение байткода, точки останова, просмотр стеков и памяти.
3. **Сборка и управление проектом** — запуск скриптов, компиляторов и ВМ из редактора с разбором диагностики.

Все три уровня реализуются стандартными средствами VSCode:
- _Language Server Protocol_ (LSP),
- _Debug Adapter Protocol_ (DAP),
- интеграция с C++/CMake,
- задачи сборки (`tasks.json`).
