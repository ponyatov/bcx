# Среда разработки

Для сборки и отладки [[bcx]] требуется минимальный, но полностью свободный набор инструментов. Никаких проприетарных IDE и тяжёлых SDK — всё ставится из штатных репозиториев Debian Linux и работает в терминале.

- [Debian GNU/Linux](https://www.debian.org/doc/manuals/debian-faq/getting-debian.ru.html) 12+
- [VSCode](https://code.visualstudio.com/docs/setup/linux) 1.92+
- GNU gcc / g++ / gdb
- GNU make / CMake

|Компонент|Назначение|
|---|---|
|`gcc`/`g++`|компиляция ядра ВМ и компилятора байткода (C++17)|
|`gdb`|пошаговая отладка, точки останова, просмотр стеков|
|`make`|скрипты управления проектом|
|`cmake`|сборка и кросс-компиляция|
|`flex`/`bison`|генерация лексера и парсера инфиксного компилятора|
|`ragel`|генерация регулярных парсеров для MCU|
|`git`|версионирование и клонирование репозитория|
|`VSCode`|IDE: среда разработки и отладки|

## клонирование

```sh
$ git clone -o gh -b dponyatov https://github.com/ponyatov/bcx.git ~/bcx
$ cd ~/bcx
$ make install
```
