# Цикл выборки/исполнения

Интерпретатор байткода работает по классической схеме:

1. [debug] проверить текущий `Ip` на наличие в таблице `breakpoint[addr]`
2. прочитать байт по адресу `op=M[Ip]`;
	- [debug] с проверкой выхода `Ip` за границу скомпилированного кода `M[0..Cp]`
3. декодировать опкод `op` $\rightarrow$ `cmd()`
	- `switch/case`,
	- `map<op,*cmd>` или
	- таблица указателей на функцию `<*cmd()>[op]`
4. выполнить соответствующую функцию, реализующую команду ВМ
	- при необходимости команда сама читает свои параметры из памяти кода, сдвигая `Ip`
	- в процессе выполнения команды 
		- [debug] проверяются стеки, регистры и выходы за границы
		- [debug+trace] выдать отладочную информацию в канал трассировки

`lib/vm/*/vm.?pp`

```cpp
/// @brief bytecode interpeter core
int vm() {
    info("\nvm:\n");
    while (true) {
        trace( "\n%.4X: ", Ip);
        assert(Ip < Cp);
        Op op = (Op)M[Ip++];
        trace( "%.2X ", (byte)op);
        switch (op) {
            case Op::nop:
                nop();
                break;
            case Op::halt:
                halt();
                break;
            default:
                trace( "???\n");
                abort();
        }
    }
    return 0;
}
```
