# DAP-сервер и жизненный цикл отладочной сессии

Расширение работает с ВМ в отладочной сборке, которая предоставляет отладочный интерфейс по протоколу **Debug Adapter Protocol (DAP)**:
[dap://127.0.0.1:4711](dap://127.0.0.1:4711)

Всё, что нужно IDE (выполнение кода из редактора, командная консоль, пошаговое исполнение, просмотр стеков, памяти и словаря, дизассемблер, логирование,..) предоставляется виртуальной машиной в динамике.
