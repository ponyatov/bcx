# Отображение графов

- вызовов
- data flow
- зависимости процессов и модулей
- топологии процессов, узлов и каналов в кластере
- топологии сети включая смежные компоненты и периферийные устройства, на которых нет активных ВМ

> полезно при отладке, анализе или реверс-инжиниринге чужого или легаси-кода, для документирования ПО

данные собираются в динамике за счёт встроенных отладочных средств ВМ:
- можно отображать конфигурацию системы выборочно, индивидуально формируя её состояние отдельными тестами
