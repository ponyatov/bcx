# Формат байткода

Поток опкодов — это плоская последовательность байт:
- первый байт команды всегда опкод `op`;
- для команд с операндом за ним следуют 1+ байт непосредственного значения или адреса в порядке little-endian.
- для экономии памяти на самых частых командах введены варианты опкодов с разными размерами операнда и суффиксами:
	- `b` `byte`: `u8`
	- `a` `addr`: `i16`/`u16`
	- `c` `cell`: `i32`/`u32`
	- `i64`/`u64` не поддерживаются т.к. основной target это MCU
	- адресация физической памяти, или виртуальной памяти ВМ не поддерживается из соображений безопасности кода
